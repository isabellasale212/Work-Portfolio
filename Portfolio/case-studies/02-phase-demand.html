The question it answers

A session total tells you how much an athlete did — not when. This dashboard splits the feed on Catapult’s phase flag so staff can see exactly where the demand sits, and sequence the training week so high-speed exposure is deliberate rather than accidental.

  • Segmented on the phase flag, with distance from the odometer and peak speed per block.
  • Cross-filtered — pick a phase and every metric, the trend and the zone split recompute to that block.
  • Readable in seconds — the shape a coach needs before the shape a spreadsheet gives.
Insight the drill-down surfaces

Peak speed of 21.0 km/h came in movement prep, not the game — warm-up design already exposes athletes to near-maximal velocity, which matters for hamstring-injury management. You only see that by filtering to the phase.

On the tooling

In a club, I build this in Power BI — Power Query to shape the export, DAX measures for distance and peak speed per phase, cross-filtering between visuals. I rebuilt it here as a live web app so you can actually interact with it in a portfolio, on the same real data and the same modelling logic. A native .pbix is available on request.

Skills demonstrated: data shaping, measure design, cross-filtered interaction, and information design for a non-technical audience.
